Accessibility

Accessibility Statement

Accessibility information for Anderson Home Services, including usability goals, known limitations, and contact options for help.

Effective date: May 2026

Anderson Home Services aims to make this website usable for as many people as possible, including people using phones, screen readers, keyboard navigation, zoom, or assistive technology.

Accessibility efforts

The website is built with responsive layouts, readable contrast, descriptive image alt text where practical, keyboard-accessible links, and a skip link for jumping to the main content.

Known limitations

The project intake form is embedded through Tally, so some form accessibility behavior is controlled by Tally. Some older portfolio photos may not be perfect, but captions and alt text are used to provide context.

Feedback

If you have trouble using the website, reading content, submitting the form, or accessing any page, contact me and I will try to provide the information or service another way.
